# Orange Blossom Website

This repository now includes a simple static website starter for launching and managing an RV business website.

## Files

- `index.html` - Main website content
- `styles.css` - Site styling

## How to manage the website

You can update the website by editing `index.html`:

- Change the business name, tagline, and contact details
- Update service descriptions and pricing text
- Replace the placeholder about section with your story
- Add your booking, quote request, or social links

## How to preview locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
